# Mis herramientas

- **Editor de código**: Visual Studio Code.
- **Servidor local**: XAMPP (Apache + PHP + MariaDB).
- **Gestor de bases de datos**: DB Browser for SQLite para los `.db`, y la terminal o Workbench para MySQL.
- **Control de versiones**: Git y GitHub (mi repositorio `2-DAW`).
- **Navegador**: Chrome con las herramientas de desarrollador (F12).
