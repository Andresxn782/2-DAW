# Generación dinámica de páginas web

Unidad 5: separar la lógica de negocio de la presentación, controles de servidor, interfaz generada dinámicamente, programación orientada a objetos con el patrón modelo-vista-controlador, y prueba y documentación del código.

Todos los ejemplos usan los datos del gimnasio Velnora. Están hechos por Andres Ruiz.
