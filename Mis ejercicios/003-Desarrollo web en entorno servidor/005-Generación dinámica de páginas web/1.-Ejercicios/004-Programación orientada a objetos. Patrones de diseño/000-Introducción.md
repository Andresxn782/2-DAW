# Programación orientada a objetos. Patrones de diseño

Paso las funciones de acceso a datos a una clase, la mejoro paso a paso y al final aplico el patrón modelo-vista-controlador (MVC) a Pulso, el panel del gimnasio que empecé en la unidad 4.

| Archivo | Qué cambia |
|---|---|
| `002` | Funciones sueltas para leer, insertar y borrar |
| `003` | Las mismas funciones dentro de una clase |
| `005` | Constructor: la conexión se abre una vez |
| `006` | La base de datos se pasa como parámetro |
| `007` | Propiedades privadas, excepciones y consultas preparadas |
| `008` | Modelo + vista + controlador juntos |
| `009` | Método estático |
| `014-pulso` | Pulso tal como quedó en la unidad 4 (punto de partida) |
| `015-pulso con mvc` | Pulso reescrito con las clases VelnoraModelo, VelnoraVista y VelnoraControlador |
| `016-pulso con config` | Igual que 015, con la identidad visual en `config.php` |
