# CLAUDE.md — Repositorio 2-DAW

## Quién soy
- Andrés, estudiante de 2º de DAW (Desarrollo de Aplicaciones Web).
- Este repo es mi material y mis ejercicios del curso. Todavía no trabajo en el sector: estoy aprendiendo.

## Cómo quiero que me ayudes
- Respóndeme siempre en **español**.
- Explícame el **porqué** de las cosas, no solo el código: quiero aprender, no copiar.
- Si hay una forma más simple de hacerlo con lo que hemos visto en clase, usa esa antes que algo avanzado.
- Si vas a usar algo que no hemos dado (frameworks, librerías), avísame primero.
- Comenta el código en español y con nombres de variables claros.

## Tecnologías del curso
- **Cliente:** HTML, CSS y JavaScript "vanilla" (sin frameworks).
- **Servidor:** PHP con **PDO** y bases de datos **SQLite** (`.db`).
- **Datos:** ficheros JSON y CSV.
- **Utilidades:** scripts sueltos en Python (`carpetas.py`, `quitarpuntos.py`, `sanearresultados.py`).
- Algún ejercicio usa **Ollama** (IA local) desde PHP.

## Estructura del repo
Las carpetas siguen los módulos y temas del curso, numerados:
- `001-Planificación de interfaces gráficas/`
- `002-Desarrollo web en entorno cliente/`
- `003-Desarrollo web en entorno servidor/`
- `004-Despliegue de aplicaciones web/`
- `005-Proyecto Intermodular II/`
- `Mis ejercicios/` → mis prácticas y proyectos propios.
- `diseño de interfaces/` → prácticas de Diseño de Interfaces.
- `Resultados de aprendizaje y criterios de evaluación.md` → lo que me evalúan en cada módulo.

Cada tema tiene un `000-Introducción.md` con los apuntes y los ejercicios numerados (`001-...`, `002-...`).

## Normas
- Mantén la numeración y el estilo de nombres de carpetas y archivos.
- No borres ni muevas apuntes ni ejercicios sin preguntarme.
- No subas contraseñas ni claves a GitHub.
- Cuando hagas un ejercicio, comprueba que cumple los criterios de evaluación del tema.
