# Establecimiento de conexiones

Para acceder a datos, primero hay que conectar con el almacén donde están. En este apartado:

- `001-Acceso a datos.md`: apuntes sobre las formas de conectar desde PHP (SQLite3, PDO y mysqli).
- `002-phpinfo.php`: comprobar qué extensiones de acceso a datos tiene PHP (`pdo_sqlite`, `pdo_mysql`, `gd`...).
- `003` a `011`: una imagen también es un almacén de datos. Leo y escribo píxeles con la extensión GD, y llego a guardar un texto dentro de una imagen y volver a leerlo.
- `012` a `014`: conexiones a bases de datos de verdad, con SQLite3, con PDO y con MySQL de XAMPP.
