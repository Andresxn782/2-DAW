# Generación dinámica de páginas web interactivas

Unidad 8: juntar el código del servidor (PHP) con el del cliente (JavaScript) para hacer páginas que reaccionan sin recargar: búsquedas mientras se escribe, un chat que se actualiza solo, formularios que se validan en los dos lados y páginas cuyo contenido y estructura cambian en directo.

Todos los ejemplos son del gimnasio Velnora y están hechos por Andres Ruiz.
