# Aplicaciones que reutilizan código e información

| Tipo | Ejemplo | Qué reutiliza |
|---|---|---|
| Red social | Instagram, LinkedIn | Mapas para la ubicación, inicio de sesión con Google o Apple, CDN para las fotos |
| Buscador | Google | La información de millones de webs, que lee y ordena |
| Correo electrónico | Gmail | Protocolos estándar (SMTP, IMAP), filtros antispam, el calendario |
| Streaming | Netflix, Spotify | Repositorios de vídeo y música, recomendadores, pasarelas de pago |
| Juego interactivo | Duolingo | Síntesis y reconocimiento de voz, notificaciones, estadísticas |
| Deporte | Strava, apps de gimnasio | GPS, mapas, datos del reloj o del pulsómetro, el tiempo |

En Velnora ya he ido reutilizando cosas:

- La API de clases (unidad 7) la usan el panel de recepción y el probador de la documentación.
- El motor `VelnoraCSV` (unidad 6) lo vuelvo a usar en el ejercicio 004 de este apartado.
- La predicción de la AEMET (unidad 7) es información de otros que mi web aprovecha.
