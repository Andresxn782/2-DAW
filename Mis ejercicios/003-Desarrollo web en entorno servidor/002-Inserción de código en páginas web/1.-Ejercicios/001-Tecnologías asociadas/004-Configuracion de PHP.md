# Configuración de PHP

PHP se configura con el archivo `php.ini`.

- En Linux: `/etc/php/8.X/apache2/php.ini`
- En XAMPP (Windows): `C:\xaampp\php\php.ini`

Cosas que he tocado o mirado: `display_errors = On` para ver errores mientras aprendo,
y `extension=sqlite3` para poder usar bases de datos SQLite.
