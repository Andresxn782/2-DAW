# Proyecto de la unidad 2: Ficha del socio

Proyecto resumen de la unidad, hecho por Andres Ruiz para el gimnasio Velnora.

Es la ficha de un socio con su cuota mensual calculada en PHP. Usa todo lo de la unidad:

- etiquetas `<?php ?>` y `<?= ?>` dentro del HTML;
- variables de todos los tipos (entero, decimal, cadena, booleano, array y null);
- conversiones implícitas y explícitas (`(int)`, `(float)`, `intval`, `settype`);
- operadores aritméticos, de comparación, lógicos, de concatenación y de asignación;
- ámbito de variables: local, `global` y `static` dentro de funciones;
- directivas: `declare(strict_types=1)` al principio de `index.php`, y `ini_set`/`error_reporting` en `index.php`.

## Cómo probarlo

Abrir `index.php` en XAMPP. Se puede cambiar el socio con `?socio=1`, `?socio=2` o `?socio=3`.
