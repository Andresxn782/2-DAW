# Utilización de conjuntos de resultados

Un conjunto de resultados es lo que devuelve una consulta: varias filas con varias columnas. En PHP lo puedo recorrer de muchas formas y también guardarlo y cargarlo en JSON, que permite datos anidados (un socio con varias reservas dentro).

- `001-Modelo de datos.md`: diferencia entre una tabla plana y un documento anidado.
- `002-ficha del gimnasio.md`: toda la información del gimnasio como un árbol.
- `003-cargarjson.php`: leo `gimnasio.json` y lo recorro.
- `004-demostracion.php`: guardo y cargo JSON con mi clase `VelnoraJSON`.
- `005-modos de recuperacion.php`: los distintos modos de `fetch` de PDO.
- `006-agrupar resultados.php`: agrupo y resumo un conjunto de resultados con SQL y con PHP.
