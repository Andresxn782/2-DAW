# Programación basada en lenguajes de marcas con código embebido

Ejercicios de la unidad 3 rehechos por mí (Andres Ruiz) a partir de los vistos en clase.
Todos usan como ejemplo el gimnasio de **Velnora**, una empresa ficticia, para que
cada ejercicio tenga sentido dentro de una misma idea.

Para probarlos: copiar la carpeta dentro de `htdocs` de XAMPP y abrir
`http://localhost/...` en el navegador.
