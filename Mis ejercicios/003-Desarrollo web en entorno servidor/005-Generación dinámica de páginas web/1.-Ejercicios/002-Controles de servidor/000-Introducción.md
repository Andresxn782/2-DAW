# Controles de servidor

Un control de servidor es un elemento de la interfaz (un desplegable, unas casillas, una tabla) que no escribo a mano en el HTML, sino que lo genera el servidor a partir de datos. Si los datos cambian, el control cambia solo.

En `controles.php` creo funciones que generan controles de formulario a partir de arrays, las uso en `001-controles.php` con arrays, y en `002-controles con base de datos.php` las relleno con los datos de `socios.db`.
