# Lenguajes de marcas (y compañeros)

Lo que el servidor suele generar o leer:

- **HTML**: estructura de la página.
- **CSS**: estilo (técnicamente es un lenguaje de hojas de estilo).
- **JS**: comportamiento en el navegador (es un lenguaje de programación).

Formatos de datos que también usaremos:

- **JSON**: intercambio de datos entre programas. `{"socio":"Lucía","plan":"Mensual"}`
- **MD (Markdown)**: documentación, como este archivo.
- **YAML**: archivos de configuración.
- **XML**: datos estructurados con etiquetas, como HTML pero con las etiquetas que tú quieras.
