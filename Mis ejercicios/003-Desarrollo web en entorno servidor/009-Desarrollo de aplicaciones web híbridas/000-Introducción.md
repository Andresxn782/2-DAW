# Desarrollo de aplicaciones web híbridas

Unidad 9: aplicaciones que juntan código y datos de varios sitios. Uso librerías de terceros (jQuery, Chart.js), reutilizo código de unidades anteriores, leo repositorios de información (JSON, CSV, XML, SQLite), incorporo funcionalidades de una red social y analizo un volumen grande de datos para sacar indicadores de negocio.

Todos los ejemplos son del gimnasio Velnora y están hechos por Andres Ruiz.
